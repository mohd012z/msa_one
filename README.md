# MSA One

MSA One is an all-in-one AI office workspace prototype for documents, spreadsheets, presentations, PDF, Smart HTML, dashboards, AI reading/presenting, conversion, and automation.

## Current build

- Premium mobile UI
- English / Bahasa Melayu interface support
- Malay presenter options
- Full-page AI workspace
- Full-page MSA One Premium experience
- Compact draggable AI Lens
- Mobile safe-area and bottom-navigation handling
- Responsive Home, Files, Create, AI and Me pages

## Android build

GitHub Actions builds a debug APK using Capacitor. Open **Actions → Build MSA One APK** to inspect a build, then download the `msa-one-debug-apk` artifact from a successful run.

> This repository currently contains the UI/prototype layer. AI, Office document generation/conversion, voice presenter, storage, and other production services require their corresponding native or backend implementations before release.
